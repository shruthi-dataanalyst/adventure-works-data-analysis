# Adventure Works Data Analysis

## Project Overview

This project analyzes Adventure Works sales data to identify sales performance, product performance, customer insights, and regional trends.

## Tools Used

- Excel
- SQL
- Power BI
- Tableau

## Project Work

### Excel
- Data cleaning and transformation
- Data validation
- Pivot tables
- Charts and dashboards
- KPI analysis

### SQL
- Data querying
- Joins
- Aggregate functions
- GROUP BY and HAVING
- Subqueries
- Window functions

### Power BI
- Data cleaning using Power Query
- Data modeling
- DAX calculations
- Interactive dashboard
- KPI and sales analysis

### Tableau
- Data visualization
- Filters
- Calculated fields
- Interactive dashboards

## Key Analysis

- Sales performance
- Product performance
- Customer analysis
- Regional analysis
- Time-based sales trends
